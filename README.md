# Arbitrary Precision Calculator (APC)

## Overview

A command-line calculator implemented in C to perform arithmetic operations on large integers that exceed the normal range of built-in integer data types.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Doubly Linked List-based number representation

## Technologies Used

- C Programming
- Pointers and Dynamic Memory Allocation
- Doubly Linked Lists
- Data Structures and Algorithms

## Compilation

Compile the source files using GCC. Example:

```bash
gcc *.c -o apc
```

Run on Linux:

```bash
./apc
```

## Learning Outcomes

Practiced linked-list manipulation, carry and borrow handling, and arithmetic operations on large integers.
